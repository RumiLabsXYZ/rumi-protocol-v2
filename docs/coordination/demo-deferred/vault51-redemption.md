# Vault 51 redemption — actual omissions

- **V51-DEF-1; owner: release coordinator.** Generalized claim collateral, a new ICRC ledger, transferable claim markets and claim-history charts are omitted. This migration is hard-coded to the authorized vault 51 and uses its existing nICP configuration. Revisit before supporting another vault or advertising transferable/withdrawable claims. Existing historical charts still describe historical token events, not current claim custody.
- **V51-DEF-2; owner: release coordinator.** Settled-collateral release is deferred. ICP remains in the dedicated protocol account, with repayment available and ordinary collateral actions suspended even after settlement. Implement and verify an explicitly authorized release/return-to-ordinary-vault path before offering withdrawal. This does not prevent initiating the requested redemption.
- **V51-DEF-3; owner: operator.** No real-funds withdrawal/settlement canary is included in software verification. The first authorized withdrawal must produce the exact WaterNeuron request, and later the exact ICP receipt/balance, before claiming those outcomes. Do not treat builds, quotes or the founder's commitment as settlement proof.
