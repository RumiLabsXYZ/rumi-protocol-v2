## Agreed behavior

The backend ranks eligible vaults globally by normalized distance from the red end of the existing collateral-ratio text color ramp, groups only adjacent vaults of the same collateral, and permits one such run and one collateral token per redemption. The same token can appear again later in the queue. The first run's amount is debt-backed capacity for its eligible vaults, not all collateral units held by every vault of that token. The queue is recalculated after each transaction, so the initial run is not a promise to drain all of its collateral before another asset can rank first.

The numeric shade-order is:

```text
headroom = (currentCR - liquidationCR)
           / (1.351 × borrowThresholdCR - liquidationCR)
```

Lower scores rank first. With the example thresholds, ICP at 150% CR (150% borrow threshold, 133% liquidation) scores about 0.244; ckXAUT at 145% CR (118% borrow threshold, 112% liquidation) scores about 0.696. Thus ICP ranks first even though ckXAUT's raw CR is lower. Redemption tier is a deterministic tie-break after health.
